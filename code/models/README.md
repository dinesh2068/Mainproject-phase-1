# Runtime models

- `yolo26n.pt`: vehicle detector for video.
- `indian_plate_yolo26s.pt`: Indian plate detector.
- `ocr_text_det_v5/` and `stock_en_PP-OCRv5_mobile_rec/`: default stock PP-OCRv5 models.
- `awiros/`: optional measured Awiros reader, selected using `tools/select_measured_reader.py`.

Model licenses and provenance are retained with their files and under `docs/model-provenance/`. Third-party terms remain applicable. Rejected fine-tuned and fastplate experiment weights are excluded. Configuration defaults remain unchanged.
